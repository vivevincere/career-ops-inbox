# career-ops inbox: privacy policy

career-ops inbox is a personal tool used by one person (its owner) to sort recruiter emails in their own Gmail account. It is not offered to anyone else.

**What it accesses.** With the owner's permission, it reads messages in the owner's Gmail, adds labels to them, and creates draft replies. It never sends email.

**Where data goes.** Message content is processed on the owner's own computer and stored there. It is not sold, shared, or sent to any third party, except that message text is passed to the owner's own AI assistant account for summarizing. It is not used for advertising.

**Google user data.** Use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Removing access.** The owner can revoke access at any time at https://myaccount.google.com/permissions and delete the local data.

Contact: the repository owner on GitHub.
